# AngelDoesStuff
My Personal Website
## Description
Hello :) This is the personal website I created for Hack Club's Stardance challenge. It features two photographs I've taken, a bit about me and my skills, links to my school projects, a link to my GitHub profile, and a link to a folder of all the compositions and arrangements I've made. This website was developed in VS Code with HTML and CSS. It took over 7 hours to create, and I'm very proud of it :)

### Dependencies

### Executing Program

- Explore the page
- Use the navigation bar to navigate through the pages and return to the home page
- Enjoy :)
